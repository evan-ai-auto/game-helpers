# 暂缓问题

## BG-HOST-RELAYOUT（低）

后台切到**大于宿主**的分辨率时，宿主往往不会自动放大，完整大窗裁切暂不可靠。仍坚持纯后台。暂缓。

## MULTI-RES（低 · 延后）

**约定推进顺序（与产品一致）：**

1. 先在 **800×600** 把功能做完并验收  
2. 资产目录已按分辨率拆好：`data/assets/ui/resolutions/{WxH}/`  
3. 功能完成后再由你提供 1024×768 等资产并单独验证  

运行时按客户区选目录；缺档报错，不静默混用。  
旧单文件模板在 800×600 上曾出现打开态误判（NCC≈0.43），已用 `resolutions/800x600` 新模板替代。
